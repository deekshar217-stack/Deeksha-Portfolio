# Deeksha R — Student Portfolio

## Folder contents
- `index.html` — page structure and portfolio content
- `style.css` — colors, layout, responsive styling, animations
- `script.js` — mobile menu, scroll reveal, active navigation, back-to-top
- `assets/Deeksha_R_Resume.pdf` — resume used by the download button

## Run in VS Code with Live Server
1. Extract this folder from the ZIP.
2. Open VS Code.
3. Choose **File → Open Folder** and select `deeksha_portfolio`.
4. Install the **Live Server** extension (Ritwick Dey).
5. Open `index.html`.
6. Right-click inside the file and select **Open with Live Server**.
7. Your browser should open the local portfolio page.
